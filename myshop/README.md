# myshop

`myshop` is a static starter storefront built for GitHub Pages.

## Features

- Responsive storefront layout
- Product search and category filtering
- Interactive cart (add, remove, quantity updates)
- Cart persistence with `localStorage`

## Local preview

From the repository root (`/home/runner/work/heera00.github.io/heera00.github.io`):

```bash
python3 -m http.server 8080
```

Then open:

- `http://localhost:8080/myshop/`

## GitHub Pages usage

Once changes are published, access the storefront at:

- `https://iamheera.me/myshop/`
